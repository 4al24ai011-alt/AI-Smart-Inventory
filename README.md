# AI-Powered Smart Inventory and Demand Prediction

## About the Project
This project aims to develop a smart inventory management system using Python and Artificial Intelligence.

It helps monitor product stock, identify low-stock products, and predict future product demand.

## Features
- Inventory dashboard
- Product stock monitoring
- Low-stock alerts
- Product details
- Stock analysis charts
- AI-based demand prediction (planned feature)

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
